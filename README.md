# Ego 采集与处理

在 Windows 上录制头戴双目、手套触觉和固定 EXO 相机，完成标定、时间对齐和选段。安装后照下面的步骤录一条短拿放，就能检查这套设备是否适合开始正式采集。

本仓库提供「采集与处理」和「物理交互工作流 → 01 · 片段输入」。在 01 中可以并排回看双目、查看原始触觉和编辑时间标注。02–08 的计算功能暂未发布。录制、配置和厂商运行环境由各工作站保存在本机。

## 采集与处理 SOP

**00 设备与标定 → 01 录制 → 02 导入与复核 → 03 整理与验收 → 04 选段与交接**

第一次上机先录一条短拿放。手边只有电脑时，先走[无硬件演练](#无硬件演练)。

## 安装与启动

准备 Windows x64 电脑、匹配的头戴双目和左手手套。EXO 可用 1–3 台固定相机，手机可放在固定机位独立拍摄。再准备一个所有相机都能拍到的二维码屏幕。需要计算桌面空间位置时，准备打印的 ChArUco 标定板。

GitHub 上点 **Code → Download ZIP**，解压后在含 README 的文件夹打开 PowerShell。安装 64 位 Python 3.11，再运行以下命令。[仓库](https://github.com/foutiam/ego) · [Python Windows 下载](https://www.python.org/downloads/windows/)

```powershell
py -3.11 --version
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r configs\ego-capture-requirements.txt
.\.venv\Scripts\python.exe scripts\serve_ego_capture.py
```

电脑打开终端显示的「采集工作台」，默认是 `http://127.0.0.1:8793/ego-capture/`。如果用另一台手机显示二维码，让它和电脑连同一 Wi‑Fi。运行 `ipconfig` 找到那张网卡的 IPv4 地址，用实际地址替换下方示例，再用这一行启动。手机打开终端输出的「手机二维码」地址，默认端口 8765。

```powershell
.\.venv\Scripts\python.exe scripts\serve_ego_capture.py --qr-bind 192.168.1.23
```

### 选择自己的保存位置和档案

首次启动会在解压目录内生成本机设置和 `recordings/`。在 **01 录制 → 路径设置** 选自己的保存目录，或展开导入与导出、EXO 与手套档案。支持跨盘、空格、中文路径和单独添加文件。留空的导入、导出、EXO 目录随录制目录走。改路径后等手头任务结束，在启动窗口按 Ctrl+C，再运行原命令。旧录制留在原目录。需要指定一份已有工作站配置时，可用 `--config`。

## 00 设备与标定

1. 在「左右目确认」遮一下物理左镜头，核对变暗的是哪一路，再保存对应关系。
2. 活动手指或轻压，确认手套实时小图响应。需要 OpenXR 骨架时，从「设备参数与校验状态 → 设置 EXO 与手套档案」选择配套 QnBot 运行环境的 `python.exe`。重启后按页面提示标定，再确认骨架随手移动。静置基线可以在设备页采集 3 秒。[QnBot 文档](https://docs.qnbot.com/zh-CN)
3. 要计算固定 EXO 的桌面位姿，点「下载桌面标定板」获取 ChArUco 板，按 100% 打印，实测格长。固定机位、方向、裁切和镜头。每台相机拍一小段同一块固定桌面板。已有匹配内参可复用，缺档时另外从不同距离和角度拍一段移动标定板的录像。

「设备参数与校验状态」可以查看当前设备、历史会话或已有的 Ego `calibration.json`。历史档案以快照显示。

## 01 录制

1. 进入「实时录制」，核对双目画面、手套并选正确串口。电脑直连的 EXO 在对应预览下选来源。手机等独立 EXO 在各自设备上点录制，电脑的相应 EXO 槽位保持「不使用」。
2. 点 **开始录制**。让双目和各路 EXO 在首尾分别拍清**同一个持续更新的动态二维码**。可以依次给各个相机看。建议两次有效观察间隔至少 10 秒，每次约拍 5–10 秒。若手机用于拍摄 EXO，用电脑或另一块屏幕显示码。
3. 启用默认的「任务前后做视触校准」时，在任务前用戴手套的手做一次相机能看清、短促有力的按压，松开后点 **开始任务**。完成拿放后点 **结束任务**，再按一次。两次校准动作留在原始录制，正式选段在任务区间内。
4. 点 **停止并保存**，工作台会进入 **02**。独立 EXO 停止后复制原始 MP4／MOV 到电脑，保留原始帧时间戳，避免剪辑或重编码。

## 02 导入与复核

1. **EXO 原片与标定。** 点「添加 EXO 原片」选手机或相机视频，再在 EXO 1–3 卡片选各自原片。只需要视频同步时选 **仅对时**。需要桌面位姿时选 **对时＋桌面标定**，再选择固定板录像、匹配的内参 JSON 或多角度内参录像，并填写实测格长。固定板录像也在「添加 EXO 原片」中添加，内参 JSON 用「添加内参 JSON」选择。最后点 **保存 EXO 选择**。只使用头戴与手套时可留空。
2. **视触复核。** 有任务前后校准的会话会先准备逐帧画面和触觉曲线。分别打开「任务前」「任务后」，选择看得清的相机，找到上一帧还未接触、当前帧首次接触的画面，点击触觉上升起点，再点 **确认对帧**。看不清可换视角或明确跳过该段。两端有效时，整理使用两处延迟在正式区间内插值，保留原始触觉数值和时间。
3. 核对顶部 EXO 与视触状态，点 **去 03 整理与验收**。在这个页面可以离开后从 01 的会话列表继续。

## 03 整理与验收

选对应会话，点 **开始整理**。工作台处理头戴双目、手套和已选 EXO，检查以下结果后进入 04。

| 核对项 | 看什么 |
| --- | --- |
| 录像与触觉 | 有双目配对和有效手套帧。正式任务起止内能看到要保留的动作。 |
| 相机对时 | 各路有清楚的首尾二维码时间依据。处理记录给出偏移与漂移估计。二维码残差是拟合误差，曝光差需用共同可见的事件抽查。 |
| EXO 桌面标定 | 仅对时的摄像机可以跳过此项。做空间标定的机位检查留出误差，当前桌面验收界为 RMS ≤ 3 px。 |
| 视触复核 | 两端已确认时，检查应用后的触觉时间和首次接触画面。跳过的会话保留当前可用的时间依据。 |

失败时可回到 02 补文件或修正选择，再开始整理。EXO 的逐相机结果可在 02 的「查看结果」打开。

## 04 选段与交接

1. 选会话，打开「自选区间与送入工作流」。按画面标记起点和终点，填片段名，点 **应用选区 → 加入工作流**。
2. 打开 **物理交互工作流 → 01 片段输入**。左右眼并排回看，点击原始触觉曲线可跳到对应画面。有校准时可切换校准时间和原始接收时间，也可在当前帧添加或修改事件标注。
3. 回到 04 的「录制文件」，点 **导出完整原始录制 ZIP**。接收方解压，把含 `metadata.json` 的整个会话文件夹放到 **01 录制 → 导入已有 Ego 会话** 显示的目录，再从 02 继续。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 手机打不开二维码 | 打开终端打印的手机地址，核对同一 Wi‑Fi 与网卡 IPv4。端口冲突可用 `--port 8873 --qr-port 8875`。 |
| 某路二维码没扫到 | 重看同一屏幕的首尾视频，核对清晰度和曝光。 |
| 没有双目或手套信号 | 在 01 各卡片下重选来源。分不清串口时可在 Windows 设备管理器查看 COM 号。 |
| 手机 EXO 录像未出现 | 在 02 用「添加 EXO 原片」选择电脑上的原始 MP4／MOV，再在卡片选择。 |
| 桌面标定失败 | 核对固定板是否移动、实际格长、镜头和分辨率。没有匹配标定时可选仅对时。 |

## 无硬件演练

```powershell
.\.venv\Scripts\python.exe scripts\make_ego_capture_demo.py
.\.venv\Scripts\python.exe scripts\serve_ego_capture.py --config demo-station/capture.demo.json --offline --port 8873
```

1. 在 01 看到已整理的 `demo-cup-001`。演练合成会话已经准备了画面和触觉。
2. 在 02 选择该会话，EXO 1 选 `exo1-task.mp4`，EXO 2 选 `exo2-task.mp4`。保存后去 03 重新整理。要练桌面标定，可同时选择对应的 `*-table.mp4` 和 `*-lens.json`，格长保持 25 mm。
3. 进入 04，把起点 `5`、终点 `13`、名字 `demo-pick-place` 加入工作流。在 01 片段输入试点曲线、跳帧和标注。合成会话用于练习界面和数据流，实机按上面的短拿放验收。

## 采集流程参考

- Ego-Exo4D 让各路相机独立录像，用首尾动态二维码录后对时，并另行标记任务边界。[采集协议](https://doi.org/10.1007/s11263-025-02557-6) · [逐相机对时文件](https://docs.ego-exo4d-data.org/data/takes/)
- TouchScale 从视频确认抓取、放手和无接触时段，再交叉检查触觉响应和噪声。[论文 §3.2 与 §8](https://arxiv.org/html/2610.10288v1#S8)
- HOT3D 用 ChArUco 标定相机，并用独立动捕建立位姿参考。[数据采集与标定附录](https://openaccess.thecvf.com/content/CVPR2025/supplemental/Banerjee_HOT3D_Hand_and_CVPR_2025_supplemental.pdf)
