# Ego 采集与处理

在 Windows 上录制头戴双目、手套触觉和固定 EXO 相机，完成标定、时间对齐和选段。安装后照下面的步骤录一条短拿放，就能检查这套设备是否适合开始正式采集。

本仓库提供「采集与处理」和「物理交互工作流 → 01 · 片段输入」。在 01 中可以并排回看双目、查看原始触觉和编辑时间标注。02–08 的计算功能暂未发布。录制、配置和厂商运行环境由各工作站保存在本机。

## 采集与处理 SOP

**采集顺序**　安装 → 核对画面和手套 → 录一条短拿放 → 复核视触 → 整理和验收 → 正式采集。只有电脑时，可以先做文末的[无硬件演练](#无硬件演练)。

## 1. 第一次安装

准备一台 Windows x64 电脑、支持本项目串口协议的头戴双目、配套左手手套、1–3 台固定 EXO 相机、桌面 ChArUco 标定板，以及与电脑连同一局域网的手机。EXO 面板预留两台，可停用或增加一路。

1. 用有仓库权限的 GitHub 账号打开项目，点 **Code → Download ZIP** 并解压。在包含 README 的文件夹打开 PowerShell。[GitHub 仓库](https://github.com/foutiam/ego)
2. 安装 64 位 Python 3.11。下面第一行应打印 `Python 3.11.x`。如果使用 Conda 或便携版且找不到 `py`，把前两行中的 `py -3.11` 换成 `& '你的目录/python.exe'`。[Python Windows 下载](https://www.python.org/downloads/windows/)
3. 创建 Python 环境并安装依赖。

```powershell
py -3.11 --version
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r configs\ego-capture-requirements.txt

```

### 选择自己的保存位置和档案

打开 **录制目录 → 路径设置**。第一次录制也可以从「录制保存位置」进入。首次启动会自动在解压目录创建本机设置，默认把录制、导入、导出和 EXO 档案目录放在解压目录下的 `recordings/`。

点各路径旁的 **浏览** 或 **添加**，选择自己的文件夹或文件。也可以直接粘贴路径。选择不同盘符、带空格或中文的目录都可以。相对路径从本机设置文件所在目录算起。

| 配置项 | 用途 | 默认位置 |
| --- | --- | --- |
| `output_root` | 录制、整理结果和本机标定 | 配置文件旁的 `recordings/` |
| `import_root` | 要导入的完整会话文件夹 | 录制目录下的 `imports/` |
| `export_root` | 导出的录制 ZIP | 录制目录下的 `exports/` |
| `exo_video_root` | EXO 原视频和标定录像的搜索目录 | 录制目录下的 `exo-inbox/` |
| `exo_profile_root` | EXO 内参目录和新生成的可复用标定档案 | 录制目录下的 `exo-calibrations/` |
| `exo_video_files` | 单独列出分散存放的 EXO 视频 | 空列表 |
| `exo_profile_files` | 单独列出分散存放的 EXO 内参 JSON | 空列表 |
| `qnbot_runtime_python` | 本机 QnBot OpenXR 环境的 `python.exe` | 留空 |

只改录制目录时，留空的导入、导出和 EXO 目录会随它移动。已有录制仍在原目录，可通过「导入已有 Ego 会话」迁移需要的会话。分散存放的 EXO 文件可以单独添加，源文件无需移动。

点 **保存路径**。等当前录制和处理任务完成后，在启动窗口按 Ctrl+C，再运行原启动命令。网页底部「数据保存位置」会显示生效的录制目录。导入与 EXO 面板显示各自的目录，导出后会显示完整 ZIP 路径。需要携带整套工作站设置时，可用 `--config` 指定自己的配置文件。

## 2. 启动并检查设备

1. 电脑运行 `ipconfig`，找到连接手机所在 Wi‑Fi 的网卡 IPv4 地址。即使电脑同时接网线，也选手机能访问的那张网卡。用实际地址替换下面的示例值，再启动。

```powershell
.\.venv\Scripts\python.exe scripts\serve_ego_capture.py --qr-bind 192.168.1.23
```

2. **电脑**打开终端打印的「采集工作台」，默认 `http://127.0.0.1:8793/ego-capture/`。**手机**打开终端打印的「手机二维码」，例如 `http://192.168.1.23:8765/`。手机页可切换「二维码」「标定板」「同时显示」。正式对时用二维码模式，画面里的码更大。
3. 打开 **录制目录 → 实时录制**。先用自动识别。画面或触觉没有更新时，用各卡片下方的「双目串口」「手套串口」「视频来源」选择正确设备。双目左右不确定时，遮一下实际左镜头，在 **标定与同步 → 当前设备标定** 保存对应关系。
4. 活动手指再轻压一下，确认手套触觉小图有响应。采集骨架时也确认「骨架有输出」。需要 OpenXR 时，在「当前设备标定 → 设备参数与校验状态」点「设置 EXO 与手套档案」，浏览并选择配套环境的 `python.exe`。重启后按「当前设备标定」提示标定。3 秒静置基线在「更多录制工具」内，需要基线校正时再采。[QnBot 文档](https://docs.qnbot.com/zh-CN)
5. 在 **标定与同步 → 二维码对时 → 固定 EXO 相机** 下载 ChArUco 板，按 100% 打印，实测格长并固定在平桌面。每台 EXO 固定位置、分辨率和镜头设置，拍几秒清晰的桌面板，保证操作区和拿放动作在画面内。已有与机位视频设置匹配的内参 JSON 就复用，缺内参时另外从不同距离和角度拍一段板，再把板放回桌面固定位置。要用手机显示标定板时，锁定显示模式和方向、实测格长，页面接受 15–40 mm。

「设备参数与校验状态」可切换查看当前设备或已保存的录制会话，也可点「打开标定档案」查看以前的 Ego `calibration.json`。它按档案原有证据显示设备参数，查看档案不会修改当前设备。要用于 EXO 计算的镜头内参 JSON，在 EXO 面板选取。

## 3. 录一条短拿放

1. 在「实时录制」确认所有需要的画面。接到电脑的 EXO 从对应预览下选择来源。独立录制的 EXO 在电脑面板留为「不使用」，在各机上开始和停止录像。录制名称可留空，工作台会自动编号。
2. 保持默认的「任务前后做视触校准」勾选，点 **开始录制**。手机放桌面板旁，尽量让每路相机清晰拍到同一个持续变化的码。建议首尾各拍约 5–10 秒，两次有效观察间隔至少 10 秒，便于估计漂移。持续可见时可以直接完成动作。手机显示「等待采集时钟」时，先确认采集已开始。
3. 任务前，用戴手套的手指短促、有力地按一次相机能看清的物体。可以由另一只手拿着物体。松开后点 **开始任务**，完成一次拿起、移动、放下。点 **结束任务** 后再按一次，最后点 **停止并保存**。两次校准动作留在完整原始录制中，正式选段只使用任务区间。

## 4. 停止后确认对帧，再整理

1. 停止并保存后，页面自动进入 **标定与同步 → 视触复核**。等画面和曲线准备好。也可从录制目录的「核对视触校准」重新进入。
2. 分别查看「任务前」和「任务后」。选一台接触清楚的已录相机，用左右箭头找到**上一帧尚未碰到、当前帧首次碰到**的位置。再点击触觉曲线的上升起点，点 **确认对帧**。看不清时先换相机，仍无法判断就点「跳过」。
3. 首尾两次对帧都有效且共享时钟依据时，工作台用两端延迟在正式任务区间内插值。整理、正式回放和 01 使用校准后的配帧时间，原始触觉数值和接收时间保留。锚点不足时以页面的校准状态为准。
4. 到 **录制目录 → 整理详情**，确认会话已整理；如界面显示「开始整理」，点它并等待完成。看「同步检查」的逐路状态。二维码校验的是相机时间，手套接收时间和实际接触延迟在视触复核中检查。

## 5. 固定 EXO 录后处理

在 **标定与同步 → 二维码对时** 选同一录制会话，在「固定 EXO 相机」点「刷新文件」，按相机分别选择以下材料。保留原始 MP4／MOV 和时间戳。

| 面板字段 | 放在哪里或怎么选 |
| --- | --- |
| 原始录像 | 独立相机的视频放在已配置的 EXO 视频目录，或在 `exo_video_files` 里指定。电脑直连相机从本次录制选择。正式动作和二维码应在这份原视频中。 |
| 桌面标定板录像 | 固定桌面板视频放在同一目录，或同样在 `exo_video_files` 里指定。原录像已有足够清晰的固定板画面时，可选择同一文件。 |
| 内参 JSON | 从已配置的内参目录或 `exo_profile_files` 选择，匹配相机、分辨率、裁切和镜头设置。[内参示例](configs/ego-exo-intrinsics.example.json) |
| 内参录像 | 缺内参档案时，选择放在 EXO 视频目录或列在 `exo_video_files` 的多角度拍板录像。 |

输入实测格长，点 **计算 EXO 标定与对齐**，再「查看结果」。检查各路二维码偏移／漂移和桌面标定留出误差。当前桌面验收界是 RMS ≤ 3 px。有结果后可下载 `exo-session.json`，会话的 `derived/` 也保存这份记录。头戴桌面位姿只在标定板可见且检查通过的帧输出。

## 6. 在 01 验收并交接

1. 打开 **选段与标注 → 自选区间与送入工作流**。用画面设起止，或直接填录制时间，输入片段名，点 **应用选区 → 加入工作流**。
2. 打开 **物理交互工作流 → 01 · 片段输入**。并排核对双目。点击原始触觉曲线可跳到对应画面，有已应用的校准时能切换「校准时间／原始接收时间」。用「标注当前帧」保存首次接触或放手时刻，标记可从曲线上点回画面。
3. 短拿放能看清、抓住和松开处的触觉响应合理，再开始正式采集。首次上机分别核对下面三项。

| 检查 | 看到什么才继续 |
| --- | --- |
| 相机对时 | 所需相机在「同步检查」或 EXO 报告中有首尾时间码依据，能核对偏移和漂移。 |
| 桌面标定 | 所需 EXO 的留出误差通过，标定板没有移动，相机和内参对应。 |
| 视触校准 | 首尾接触能从视频和触觉曲线确认。要使用补偿的会话，在界面确认校准已应用。 |

4. 交接时回到该会话的 **选段与标注 → 录制文件 → 导出完整原始录制 ZIP**，用「复制 ZIP 路径」定位文件。接收方解压，把含 `metadata.json` 的整个会话目录放进 **录制目录 → 导入已有 Ego 会话** 显示的目录，等待导入和整理后打开 01。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 手机打不开二维码 | 用终端打印的「手机二维码」地址。检查同一 Wi‑Fi、IPv4 和专用网络端口。端口有冲突时加 `--port 8873 --qr-port 8875`，使用重新打印的地址。 |
| 手机二维码更新了，但相机对时不足 | 检查屏幕在各路是否清晰、首尾两段能否读码。放大二维码、更换位置，重录一条首尾都清晰的短拿放。 |
| 串口选错或没有画面 | 在预览卡片下重选来源。同型号设备分不清时，到 Windows 设备管理器查 COM 号。界面选择无效时可设置 `camera_port_override` 或 `glove_port_override` 后重启。 |
| 手套有触觉、骨架没有输出 | 核对匹配的 QnBot OpenXR 运行环境、`qnbot_runtime_python` 和设备标定。 |
| EXO 标定未通过 | 确认格长、板平整与机位。内参与视频尺寸、镜头或裁切有变化时，换正确档案或重新拍板。 |

## 无硬件演练

在已安装依赖的源码目录运行以下命令。演练会创建单独的 `demo-station/`。重复演练时用 `--directory` 创建另一个目录，再把启动命令换成对应配置路径。

```powershell
.\.venv\Scripts\python.exe scripts\make_ego_capture_demo.py
.\.venv\Scripts\python.exe scripts\serve_ego_capture.py --config demo-station/capture.demo.json --offline --port 8873
```

1. 打开终端打印的工作台，确认「录制目录」有已整理的 `demo-cup-001`。
2. 想练 EXO 时，在「二维码对时」选该会话。EXO 1 选 `exo1-task.mp4`、`exo1-table.mp4`、`exo1-lens.json`，EXO 2 选对应的 `exo2-*` 三个文件。格长保持 25 mm，点「计算 EXO 标定与对齐」。演练没有实拍头戴内参，头戴的桌面定位覆盖为 0 属正常。
3. 在「选段与标注」把起点 `5`、终点 `13`、名字 `demo-pick-place` 登记到工作流。打开 01，点击曲线核对画面能跟着跳，并试着写一个时间标注。合成会话用于练习界面和数据流，真实设备按第 6 节的短拿放验收。

## 采集流程参考

- Ego-Exo4D 的采集协议用首尾动态二维码对时，并单独记录任务边界。[论文采集流程](https://doi.org/10.1007/s11263-025-02557-6) · [逐相机对时文件](https://docs.ego-exo4d-data.org/data/takes/)
- TouchScale 从视频确认抓取、放手和无接触时段，再交叉检查触觉响应和噪声。[论文 §3.2 与 §8](https://arxiv.org/html/2610.10288v1#S8)
- HOT3D 用 ChArUco 标定相机，并用独立动捕建立位姿参考。[数据采集与标定附录](https://openaccess.thecvf.com/content/CVPR2025/supplemental/Banerjee_HOT3D_Hand_and_CVPR_2025_supplemental.pdf)
